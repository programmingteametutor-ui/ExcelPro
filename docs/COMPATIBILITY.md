# Formula compatibility

Generated by `npm run compat` from the functions registered in the formula engine (HyperFormula 3.x + ExcelPro plugin). Do not edit by hand.

Of the 165 functions listed in the product spec: **145 supported, 15 partial, 5 unsupported.** The engine registers 441 functions in total.

Unsupported functions are never silently replaced: the formula text is kept, the cell shows `#NAME?`, and the status bar explains which function is missing. Imported workbooks list them in the import report.

## Engine-wide differences from Excel

- Circular references evaluate to `#CYCLE!` (Excel shows 0 and a warning). Iterative calculation is not supported.
- `#NULL!` (intersection operator) is not produced; the space intersection operator is not supported.
- Dates use Excel's 1900 date system including the 1900 leap-year quirk; the 1904 system is not supported.
- Structured table references (Table1[Column]) and LAMBDA/LET are not supported.
